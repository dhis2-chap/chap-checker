For the operator playbook (version bump, tag, push, verification,
yank tips, and the trusted-publishing auth model) see
[`docs/guides/releasing.md`](docs/guides/releasing.md), which is
also rendered on the docs site at
<https://dhis2-chap.github.io/chap-checker/guides/releasing/>.
